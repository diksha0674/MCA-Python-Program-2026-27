# Python Programming Solutions – Units 2 to 4

This repository contains beginner-friendly solutions to all 15 questions from the supplied document.

## Folder structure

- `Unit_2_Functions/` – Functions, arguments, recursion, scope, lambda, modules and packages
- `Unit_3_Strings_Collections/` – Strings, slicing, lists, tuples, sets and dictionaries
- `Unit_4_Exceptions_Files_Libraries/` – Exceptions, file handling, standard libraries and command-line arguments

## How to run

1. Install Python 3.
2. Open a terminal in the folder containing the required `.py` file.
3. Run:

```bash
python filename.py
```

For Unit 2 Question 5, open the `Q5_modules_and_packages` folder and run:

```bash
python main.py
```

For Unit 4 Question 5, pass two numbers and an operator:

```bash
python Q5_command_line_arguments.py 10 5 +
python Q5_command_line_arguments.py 10 5 "*"
```

## Notes

- Programs that ask for input should be run in a terminal.
- Unit 4 Question 2 creates `student.txt` in the current working directory.
- Unit 4 Question 3 requires an existing text file; you can test it using `student.txt` created by Question 2.
- Unit 2 Question 5 uses multiple files to demonstrate a module and a package.
